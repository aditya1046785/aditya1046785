### 💬 TermiBot — AI Terminal Assistant
> *Because I kept forgetting Linux commands. So I built a fix.*

A CLI tool that lives in your terminal. Type `bot "your question"` and get instant, context-aware help powered by Gemini. Custom system prompts keep responses relevant to *your* setup.

```bash

→ find . -mtime -1
```

`Python` `Bash` `Gemini API` `Linux`
